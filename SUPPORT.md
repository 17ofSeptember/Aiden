# Support

## General Questions

For installation, configuration, training, node graphs, Arduino setup, or normal troubleshooting:

1. Read `README.md`.
2. Read `BUILDING.md` or `LINUX_SETUP.md` when relevant.
3. Search existing GitHub issues.
4. Open a bug report if behavior appears incorrect.
5. Use GitHub Discussions for general questions if Discussions are enabled for the repository.

Repository:

https://github.com/17ofSeptember/Aiden

## Bug Reports

Use the repository's structured **Bug Report** issue form.

Useful information includes:

- Aiden version
- Windows or Linux version
- X11 or Wayland on Linux
- hardware or simulation source
- Arduino model
- sensor
- relevant diagnostics
- reproduction steps

Do not publicly post sensitive recordings, secrets, or private system information.

## Feature Requests

Use the **Feature Request** issue form.

Hardware-interface proposals should explain the sensor/device, expected signal source, connection method, sampling requirements, and whether physical testing is available.

## Security

Do not report vulnerabilities in a public issue.

See `SECURITY.md` or contact:

awrynetwork@gmail.com

## Medical Questions

Aiden is not a medical device and the project does not provide medical interpretation of biosignal data.

Questions involving symptoms, diagnosis, treatment, or medical meaning should be directed to an appropriate medical professional rather than the Aiden issue tracker.
